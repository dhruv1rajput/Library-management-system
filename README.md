# Library Management System

A simple command-line Library Management System built with Python using functions and file handling.

## Features

- Add new books to the library
- Update quantity of existing books
- Display all books with total and available copies
- Search for a book by name
- Issue a book to a student
- Return an issued book
- View all issued books
- Delete a book (only when no copies are issued)
- Data is saved to and loaded from `library.txt`

## Usage

```bash
uv run library
```

Follow the on-screen menu to manage books.
